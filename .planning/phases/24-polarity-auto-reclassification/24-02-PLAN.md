<objective>
Implement the weekly polarity auto-reclassification: a single global, no-N+1
service that aggregates ReviewTag polarity per canonical tag over the trailing
window and flips `always_*` tags to `mixed` past threshold, a thin Beat task
wrapper on the default queue, and a data migration that seeds the weekly
CrontabSchedule. This turns the Plan-01 Wave-0 test suite GREEN.

Purpose: Keep each canonical tag's `polarity_type` honest automatically — no GPT
call, no manual curation — and log every flip to the existing AuditLog so the
Phase 21 Activity Log viewer surfaces it for free (POL-03 "logged" half).
Output: New `services/reclassify.py`, the `reclassify_polarity_task` in
`tasks.py`, and Beat-seed migration `0013`.
</objective>

| service → DB (cross-org aggregate) | One job process reads ReviewTag/Review and writes OrgCanonicalTag/AuditLog across all orgs; org attribution must derive structurally from FKs |

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-24-04 | Spoofing | reclassify_polarity_task trigger | mitigate | No HTTP/endpoint trigger exists; the task is Beat-scheduled only and accepts no args, so it cannot be invoked with attacker-chosen org/tag parameters |
| T-24-05 | Tampering / cross-tenant write | _flip_and_audit org attribution | mitigate | AuditLog.organisation_id and the flipped tag are read from the OrgCanonicalTag.organisation FK (never a parameter); the aggregate scopes reviews via canonical_tag_id__in candidate set so org-A reviews never enter an org-B tag's denominator (§9/§22) — covered by the multi-tenant isolation test |

| T-24-07 | Denial of Service | weekly aggregate cost | accept | Single grouped query backed by existing canonical_tag_id and (organisation, review_create_time) indexes; weekly cadence, low concurrency on the default queue — no rate-limit surface |
| T-24-08 | Elevation of Privilege | polarity_type mutation scope | mitigate | bulk_update field list is restricted to ["polarity_type","polarity_reclassified_at"]; review_count and all other fields are out of the writable set (D-03), bounding the blast radius |
