<objective>
Make the Phase 11 progress UI reflect the new two-stage Phase 12 lifecycle:
(1) ProgressModal listens for `sync.enrichment.progress` events to fill the
green AI bar in real time, swaps the static "Will be processed after sync
completes" sub-label for the live counter / "Starting AI analysis…" copy, and
gates the "Sync complete" banner behind `sync.complete` (which now fires only
when enriched >= fetched per Plan 12-06). (2) TopbarSyncIndicator tracks

fetch and "Analysing reviews with AI…" during enrichment, removing shops from
the active list only on `sync.complete`.

bell with active/failed/completed lists, but only the fetch stage was wired.

stuck at 0%, the "Sync complete" banner appearing after fetch alone, and the
bell prematurely removing shops from the active list. UI-SPEC.md §1 and §2
fully specify the contract; this plan implements both verbatim.

Output: Surgical edits to two existing tsx files; no new components; no
backend changes (Plan 12-06 already makes the events flow correctly).

```tsx
ws.onmessage = (ev) => {
  try {
    const data = JSON.parse(ev.data);
    if (data.type === "sync.enrichment.progress") {
      setActive((prev) =>
        prev.map((s) =>
          s.shop_id === shop.shop_id ? { ...s, stage: "enriching" } : s,
        ),
      );
    } else if (data.type === "sync.fetch.progress") {
      // Default stage; transition back from enriching is impossible per Plan 12-06
      // (enrichment runs strictly after fetch; once enriching, stage doesn't reset).
      setActive((prev) =>
        prev.map((s) =>
          s.shop_id === shop.shop_id && s.stage !== "enriching"
            ? { ...s, stage: "fetching" }
            : s,
        ),
      );
    } else if (data.type === "sync.complete") {
      setActive((prev) => prev.filter((s) => s.shop_id !== shop.shop_id));
      setFailures((prev) => prev.filter((f) => f.shop_id !== shop.shop_id));
      setCompleted((prev) => [
        ...prev.filter((c) => c.shop_id !== shop.shop_id),
        {
          shop_id: shop.shop_id,
          shop_name: shop.shop_name,
          total_fetched: data.total_fetched ?? 0,
        },
      ]);
      ws.close();
      sockets.current.delete(shop.shop_id);
    } else if (data.type === "sync.error") {
      // unchanged from Phase 11
    }
  } catch {
    // ignore
  }
};
```
