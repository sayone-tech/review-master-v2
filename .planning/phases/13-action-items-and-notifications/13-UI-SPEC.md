# Phase 13 — UI Design Contract

> Visual and interaction contract for Action Items and Notifications.
> Generated by gsd-ui-researcher, verified by gsd-ui-checker.

---

## Design System

| Property | Value |
|----------|-------|
| Tool | none (custom Tailwind config) |
| Preset | not applicable |
| Component library | none (hand-rolled components) |
| Icon library | lucide-react |
| Font | Geist (sans), Geist Mono (mono) |

No shadcn / Radix. All components are project-owned. Phase 13 reuses DataTable,
Modal, ConfirmModal, and TopbarBell patterns; it does not introduce new third-party
UI dependencies.

---

## Spacing Scale

Standard 8-point scale. All Phase 13 components follow the same scale as prior phases.

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps (gap-1), inline chip padding (py-0.5) |
| sm | 8px | Badge/chip group gaps (gap-2), tight row spacing |
| md | 16px | Cell horizontal padding (px-4), default element gaps |
| lg | 24px | Modal content padding (px-6), section breaks |
| xl | 32px | Between major modal sections |
| 2xl | 48px | Not used in Phase 13 modal contexts |
| 3xl | 64px | Not used in Phase 13 |

Exceptions:
- Three-dot button touch target: 32×32px (w-8 h-8) — matches existing ReviewTable
  row action button size.
- Notification bell button: 34×34px (w-[34px] h-[34px]) — matches TopbarBell.
- Modal max-height: 80vh — inherited from Modal component.
- Tab border-bottom: 2px — standard tab underline weight.

---

## Typography

All sizes match established Phase 11/12 patterns. Phase 13 declares exactly 4 type
sizes. `text-[13.5px]` (DataTable cell body text) is an inherited system value used
by the DataTable component itself — it is NOT a Phase 13 type role and is not listed
here.

| Role | Size | Weight | Line Height |
|------|------|--------|-------------|
| Body | 14px | 400 (regular) | 1.5 |
| Label / badge / chip text | 12px | 600 (semibold) | 1 |
| Section micro-label | 12px | 600 (semibold), uppercase, letter-spacing 0.05em | 1 |
| Modal heading | 18px | 600 (semibold), tracking-[-0.01em] | 1.2 |
| Table heading | 12px | 400 (regular), uppercase, letter-spacing 0.05em | 1 |
| Bell popover row title | 14px | 600 (semibold) | 1.2 |
| Bell popover detail | 12px | 400 (regular) | 1.4 |
| Overdue date | 12px | 600 (semibold), text-red | 1 |

Font: Geist sans-serif stack.

Declared Phase 13 type scale (4 sizes, 2 weights — no deviations):
- `text-[12px]` — chips, badges, muted detail lines, micro-labels, table headings
- `text-[14px]` — modal body, button labels, select boxes, row body copy, bell popover row titles
- `text-[18px]` — modal heading (Modal component h2)
- `text-[20px]` — page heading (consistent with ReviewManagementWidget)

Declared weights: 400 (regular) and 600 (semibold) only. Weight 500 (medium) is not used
in Phase 13. Table headings use `font-normal` (400) differentiated by uppercase +
letter-spacing, not by weight.

Inherited system value (not a Phase 13 type role):
- `text-[13.5px]` — DataTable cell body text, owned by the DataTable component

## Color

All values sourced from `frontend/tailwind.config.js`. Phase 13 uses no new colours.

| Role | Value | Token | Usage |
|------|-------|-------|-------|
| Dominant (60%) | #FAFAFA | `bg` | Page background, modal interior |
| Secondary (30%) | #F4F4F5 | `line-soft` | Table header bg (#FBFBFB), hover surfaces, empty state bg |
| Accent (10%) | #FACC15 | `yellow` | Primary CTA button ("+ New Action Item"), active tab underline, Save Changes button |

**File:** `frontend/src/widgets/action-items/ActionItemTable.tsx`

Wraps `DataTable` with the action-items-specific column set. Follows the same
pattern as `ReviewTable` — accepts `rows`, `loading`, `emptyState`, and callbacks.

#### Table columns (ACTN-04)

| # | Key | Label | Width hint | Content |
|---|-----|-------|-----------|---------|
| 1 | `title` | TITLE | flexible | Clickable text, `text-[14px] text-ink font-semibold cursor-pointer hover:underline` |
| 2 | `status` | STATUS | 120px | StatusBadge — decorative only, not a click target |
| 3 | `scope` | SCOPE | 90px | ScopePill — `Shop` or `Brand` |
| 4 | `shop` | SHOP | 140px | Shop name, `text-[14px] text-ink`; `—` for brand-scoped items |
| 5 | `assignee` | ASSIGNEE | 140px | Avatar + name at 14px; `Unassigned` in muted if null |
| 6 | `due_date` | DUE | 100px | Date string; red semibold if overdue (due_date < today); `—` if none |
| 7 | `created` | CREATED | 100px | Relative date (same `formatRelativeDate` helper as ReviewTable) |
| 8 | `source` | SOURCE | 60px | `Sparkles` icon (AI) or `User` icon (manual); 14px, text-muted; aria-label |
| actions | — | — | 48px | Three-dot menu (renderRowActions) |

Table uses `bg-white border border-line rounded-card overflow-hidden` container —
identical to DataTable default.

#### Skeleton loading

6 skeleton rows, same `animate-sk-pulse` pattern as DataTable. Each cell uses its
column's `skeletonWidth` — set title to `180px`, status/scope/source to `80px`,
shop/assignee to `120px`, dates to `80px`.

#### Row hover state

`group hover:bg-[#FBFBFB]` — inherited from DataTable `<tr>` class.

#### Three-dot menu (renderRowActions)

Button: `w-8 h-8 rounded-md text-muted hover:bg-line-soft hover:text-ink flex items-center justify-center`
Icon: `MoreHorizontal` size 14, aria-hidden
Opacity: `opacity-35 group-hover:opacity-100 transition-opacity` — same as ReviewTable

Menu (absolute-positioned dropdown, `z-50`):
- `w-[200px] bg-white border border-line rounded-menu shadow-lg py-1`
- Each item: `px-4 py-2 text-[14px] text-ink hover:bg-line-soft cursor-pointer`
- **Status submenu** — rendered as a nested block within the dropdown, not a flyout.
  Label: `text-[12px] uppercase font-normal text-subtle tracking-[0.05em]` separator
  above 4 status options.
- Each status option: same item style as above, with a `Check` icon (size 14,
  text-green) rendered on the left when that status is the current status.
- Visual current-status indicator: the active status row shows `Check` icon and
  `font-semibold text-ink` (bold, darker text).
- Separator line `border-t border-line-soft` above status submenu block.

Status options in order: To Do, In Progress, Complete, Won't Do.

### 2. ActionItemModal (new component)

**File:** `frontend/src/widgets/action-items/ActionItemModal.tsx`

Uses `Modal` at `size="lg"` (max-w-[640px]).

**Always opens on Details tab** — tab state initialised to `"details"`.

#### Modal header

- Title: action item's `title` field, `text-[18px] font-semibold text-ink tracking-[-0.01em]`
  (Modal `title` prop — inherits existing Modal h2 styling)
- Subtitle: `{scope} · {shop_name}` or `{scope}` for brand items, `text-[14px] text-muted mt-1`
  (inherited DataTable system value; rendered by Modal component, not Phase 13 typography)

#### Tab bar

- Tabs: Details | Notes | Source Review
- Source Review tab hidden when `source = "manual"` (ACTN-06: visible only for AI-extracted items)
- Tab bar: `flex border-b border-line gap-0 px-0` rendered inside modal scroll area at top
- Each tab button: `px-4 py-2.5 text-[14px] font-semibold text-muted hover:text-ink transition-colors`
- Active tab: `text-ink border-b-2 border-yellow -mb-px` (underline with yellow accent)
- Tab container margin-bottom: 16px (gap before tab content)

#### Details tab — read mode

Status dropdown at top of tab (CONTEXT.md decision):
- Label: `STATUS` micro-label (12px semibold uppercase muted, mb-1)
- Control: `<select>` styled inline: `px-3 py-1.5 text-[14px] bg-white border border-line rounded-md`
  with the StatusBadge colour visually suggested via the selected option text colour (CSS only,
  no custom option backgrounds — browser select styling limitations apply)
- Selecting a new status immediately triggers the status transition API call; no separate Save needed for status alone

Fields in read mode (two-column grid, `gap-x-8 gap-y-4`):

| Field | Label | Format |
|-------|-------|--------|
| Title | TITLE | `text-[14px] text-ink` |
| Priority | PRIORITY | Priority dot + label at 14px |
| Due Date | DUE DATE | Date string or `—`; red if overdue |
| Assignee | ASSIGNEE | Avatar + name or `Unassigned` |
| Shop | SHOP | Shop name; `—` for brand items |
| Scope | SCOPE | ScopePill |
| Created | CREATED | Absolute date + relative (e.g. "2 May 2026 · 3 days ago") |
| Source | SOURCE | `AI extracted` (Sparkles icon) or `Manual` (User icon) |

Edit button: `text-[14px] text-muted underline hover:text-ink` below the fields grid,
right-aligned. Label: `Edit Details`.

#### Details tab — edit mode

Clicking Edit Details transforms the title, priority, due date, and assignee fields in-place
into inputs. Scope and Shop remain as read-only text for AI-extracted items (ACTN-07).
For manually-created items, Scope and Shop are NOT editable after creation (matches AI rule).

Input styles (all same):
- `px-3 py-2 text-[14px] bg-white border border-line rounded-md w-full`
- Focus: `outline-none ring-2 ring-yellow ring-offset-0`

Editable fields:
- **Title**: `<input type="text">` with 5–200 char constraint (show count: `text-[12px] text-muted text-right`)
- **Priority**: `<select>` with High / Medium / Low options
- **Due Date**: `<input type="date">` — only today or future allowed (HTML `min` attr)
- **Assignee**: `<select>` populated from team members list

Discard Changes / Save Changes footer (rendered at bottom of modal scroll area in edit mode, NOT in Modal `footer` prop):
- `flex justify-end gap-2 pt-4 mt-4 border-t border-line-soft`
- Discard Changes: `px-4 py-2 text-[14px] bg-white border border-line rounded-md hover:bg-line-soft` — reverts inputs, exits edit mode
- Save Changes: `px-4 py-2 text-[14px] bg-yellow text-black font-semibold rounded-md hover:bg-yellow-hover` — submits PATCH, exits edit mode on success

Error inline: `text-[12px] text-red mt-2` below the save/cancel row.

#### Notes tab

Layout: scrollable note timeline above a permanently-visible compose area.

**Timeline** (oldest-first — conventional for log/audit-style sequences):
- Each note entry: `flex gap-3 py-3 border-b border-line-soft last:border-b-0`
- Avatar or user initial: `w-7 h-7 rounded-full bg-line flex items-center justify-center text-[12px] font-semibold text-muted shrink-0`
- Content block: `flex-1 min-w-0`
  - Author + timestamp: `text-[12px] text-muted` (`{name} · {relative time}`)
  - Note text: `text-[14px] text-ink mt-0.5 whitespace-pre-wrap`

**Compose area** (always visible, no toggle):
- `mt-4 pt-4 border-t border-line-soft`
- `<textarea>`: `w-full px-3 py-2 text-[14px] bg-white border border-line rounded-md resize-none h-[80px]` with 1–2000 char constraint
- Character counter: `text-[12px] text-muted text-right mt-1`
- "Add note" button: `px-4 py-2 text-[14px] bg-yellow text-black font-semibold rounded-md hover:bg-yellow-hover mt-2` — right-aligned
- Empty textarea disabled state: button `opacity-40 cursor-not-allowed`

Empty timeline state (no notes yet):
- `text-[14px] text-muted py-4 text-center` — copy: "No notes yet."

#### Source Review tab

Read-only review card (ACTN-11). Visible only for AI-extracted items.

Layout: `bg-line-soft rounded-card p-4` container.

Fields rendered:
- Reviewer name + star rating row
- Review date (relative)
- Review text (full, no truncation in modal context)
- Sentiment badge + tag chips (if enriched)

Footer link: `"Open in Reviews"` — `<a href="/admin/org/reviews/?id={review_id}" class="text-[14px] text-yellow underline hover:opacity-80">Open in Reviews</a>`

### 5. NotificationBell (new component)

**File:** `frontend/src/widgets/notif-bell/NotifBell.tsx`

Mounted at `<div id="notif-bell-root">` in `templates/partials/topbar.html`, to the
right of the existing TopbarBell (sync indicator). The two components are independent;
TopbarBell is not modified.

#### Bell button

`relative w-[34px] h-[34px] rounded-md text-muted hover:bg-line-soft flex items-center justify-center`
Icon: `Bell` (lucide-react) size 18, aria-hidden

#### Unread count badge

Position: `absolute top-0 right-0 translate-x-1/4 -translate-y-1/4`
Style: `min-w-[18px] h-[18px] px-1 bg-red text-white text-[10px] font-semibold rounded-full flex items-center justify-center leading-none`
Rendered when unread count ≥ 1. Not rendered when count = 0.
Max displayed: `99+` when count > 99.

#### Popover

Opens on bell click. Closes on outside click or Escape.

Container: `absolute top-full right-0 mt-2 w-[320px] bg-white border border-line rounded-menu shadow-lg z-50`

**Header row** (inside popover):
`flex items-center justify-between px-4 py-3 border-b border-line-soft`
Left: `"Notifications"` at `text-[14px] font-semibold text-ink`
Right: `"Mark all as read"` button — `text-[12px] text-muted underline hover:text-ink` — hidden when count = 0

**Notification list**:
Up to 10 rows, newest-first.
Each row: `flex items-start gap-3 px-4 py-3 border-b border-line-soft last:border-b-0 cursor-pointer hover:bg-line-soft`
Clicking any row: navigates to the relevant page AND marks that notification read.

Row layout:
- Left: icon column (16px wide, shrink-0, mt-0.5)
- Right: content column `flex-1 min-w-0`

Notification type → icon map:

| Type | Icon | Colour |
|------|------|--------|
| `new_review` | `Star` size 14 | text-yellow |
| `new_action_item` | `Sparkles` size 14 | text-amber |
| `action_item_assigned` | `UserCheck` size 14 | text-blue |

Row content:
- Title: `text-[14px] font-semibold text-ink` — truncated to one line (`truncate`)
- Sub-line: `text-[12px] text-muted mt-0.5` — format: `{shop_name} · {relative_time}`
  For `action_item_assigned` with no shop: `{relative_time}` only.
- Unread indicator: thin left border `border-l-2 border-yellow -ml-4 pl-[14px]` on
  unread rows (net left padding unchanged).

**Footer** (inside popover):
`px-4 py-3 border-t border-line-soft text-center` — shown only when notifications exist.
`"Mark all as read"` is in the header; footer is omitted in this design (single-location pattern).

**Empty popover state** (no notifications):
`px-4 py-8 text-center`
Icon: `Bell` size 24, text-muted, mx-auto mb-2
Copy: `"No new notifications"` — `text-[14px] text-muted`

### 6. ActionItemChip — Phase 13 upgrade (REVW-08 full delivery)

**File:** `frontend/src/widgets/review-management/ActionItemChip.tsx`

Phase 13 replaces the non-interactive Phase 12 chip with a clickable version.

**When ActionItem rows exist for this review** (determined by API returning `has_action_items: true` or by the count being meaningful — exact mechanism at executor's discretion based on API shape):
- Add `cursor-pointer` to the chip's className
- Add `onClick`: navigates to `/admin/org/action-items/?review={review_id}`
- Hover: darken background from `bg-amber-tint` (#FEF3C7) to `#FDE68A` (amber-100 approximation — use inline style `{ backgroundColor: "#FDE68A" }` on hover via `onMouseEnter`/`onMouseLeave` or a Tailwind `hover:` class if the token exists)
  Recommended: add `hover:bg-[#FDE68A]` utility class.
- `title` attribute: `"View action items for this review"`

**When ActionItem rows do NOT exist yet** (promotion task hasn't run):
- Chip remains non-interactive (no onClick, no cursor-pointer)
- Background stays `bg-amber-tint`, no hover darkening
- `title` attribute: `"Action items pending"` (tooltip signals intent without false affordance)

The phase 13 executor decides the exact boolean signal from the API; the visual contract
above is binding regardless of implementation mechanism.

## Interaction States

### ActionItemTable loading and empty states

| State | Rendering |
|-------|-----------|
| Loading | 6 skeleton rows with `animate-sk-pulse` cells |
| Loaded, rows exist | Normal row rendering |
| Loaded, empty (no items) | `emptyState` slot — "No action items yet" illustration + copy + optional CTA |
| Loaded, empty (filters) | `emptyState` slot — "No results" copy + "Clear filters" CTA |

### ActionItemModal state machine

| Mode | Details tab | Notes tab | Source tab |
|------|-------------|-----------|------------|
| Read | Fields as text, Edit Details link, Status dropdown | Timeline + compose area | Review card (AI items only) |
| Edit | Fields as inputs, Save Changes/Discard Changes at bottom | Unchanged | Unchanged |
| Edit (saving) | Inputs disabled, Save Changes button shows spinner (`Loader2`) | Unchanged | Unchanged |
| Edit (error) | Inputs re-enabled, error text shown | Unchanged | Unchanged |

### Three-dot status submenu

| State | Visual |
|-------|--------|
| Menu closed | Button at opacity-35, transitions to opacity-100 on row hover |
| Menu open | Dropdown visible, `z-50`, backdrop click closes |
| Current status option | `Check` icon left + `font-semibold text-ink` |
| Other status options | No icon + `font-normal text-ink` |
| Transitioning | Selected option row shows `Loader2` spinner briefly; toast fires on success |

### Notification bell polling

| State | Visual |
|-------|--------|
| Count = 0 | Bell icon, no badge |
| Count ≥ 1 | Bell icon + red badge with number |
| Popover closed | Popover not rendered |
| Popover open | Popover rendered, click outside closes |
| After mark-read | Count badge updates immediately (optimistic); 60s poll reconfirms |

### Action item chip (review card)

| State | Visual |
|-------|--------|
| has_action_items = true (Phase 13 rows exist) | Clickable amber chip, cursor-pointer, hover darkens to #FDE68A |

| count = 0 or null | Chip not rendered |

## Accessibility Notes

- ActionItem table title column: `<button type="button">` or `<a>` (link semantics preferred since it navigates to a filtered view). Use `aria-label="{title} — open action item"`.
- Three-dot menu: `aria-label="More actions for {title}"` on the button; dropdown uses `role="menu"` with `role="menuitem"` on each option.
- Status submenu: the `CHANGE STATUS` section label uses `role="group"` with `aria-label="Change status"`.
- Modal tab bar: `role="tablist"` with each tab as `role="tab"` and `aria-selected`. Tab panel uses `role="tabpanel"`.
- Status dropdown in modal: `<label>` associated via `for`/`id`.
- Notes textarea: `aria-label="Add a note"`, `aria-describedby` pointing to char counter.
- Notification bell popover: `role="menu"` with `aria-label="Notifications"`. Each row `role="menuitem"`. Container `aria-live="polite"` for count updates.
- Unread badge: `aria-label` on the bell button reflects the live count (e.g. `"5 unread notifications"`).
- Overdue date: `aria-label="{date} — overdue"` on the cell content.
- Source icons: `aria-hidden="true"` with `title` tooltip attribute for visual-only context.
