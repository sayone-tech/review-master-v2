<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Celery task → DB | merge task mutates ReviewTag FKs + deletes OrgCanonicalTag across many rows |
| service → cross-org data | source/target IDs could reference another org's tags |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-25-AC1 | Elevation of Privilege | merge_canonical_tags / create_merge_job | mitigate | All source/target fetches filter `organisation_id=org_id`; wrong-org id raises DoesNotExist (404), never operates cross-org. Covered by `test_merge_cross_org_blocked`. |
| T-25-AC3 | Tampering | concurrent merge jobs | mitigate | create_merge_job rejects when an active (PENDING/IN_PROGRESS) job exists (→409); task acquires non-blocking `lock:tag_merge:org:{org_id}`; whole merge in `transaction.atomic` (rollback on failure). Covered by `test_merge_rollback_on_error`. |
| T-25-05 | Tampering | rename duplicate collision | mitigate | Case-insensitive `label__iexact` check before save; DB UniqueConstraint is case-sensitive so this is the authoritative guard. Never silently merges. Covered by `test_rename_rejects_iexact_duplicate`. |
| T-25-06 | Tampering | review_count double-count | mitigate | `_refresh_review_counts` aggregate after FK re-point; naive sum forbidden (grep gate asserts 0 occurrences of `review_count +=`). |
| T-25-SC | Tampering | npm/pip installs | accept | No new packages this plan (RESEARCH Package Legitimacy Audit: none added). |
</threat_model>
