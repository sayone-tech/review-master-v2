## Surface Specifications

### Surface 1 — Regions List Page (`/admin/org/regions/`)

**Primary focal point:** yellow "Create Region" CTA button in the page header — the only high-contrast element on the neutral background.

**Layout:**
- Extends `base_org.html`
- Page header: "Regions" heading (left) + "Create Region" button (right, yellow CTA, `+` icon left)
- Django template mounts `<div id="region-modals-root">` always + `<div id="region-table-root">` when `regions_count > 0`
- Empty state: rendered by React inside `DataTable`'s `emptyState` prop

**Table columns (when rows exist):**

| Column | Key | Accessor | Width hint |
|--------|-----|----------|------------|
| Region Name | `name` | `text-[13.5px] font-normal text-ink` | `skeletonWidth: "140px"` |
| Region ID | `region_id` | `RegionIdBadge` component | `skeletonWidth: "80px"` |
| Actions | — | Edit + Delete icon buttons (direct, no three-dot menu) | `w-20` |

**Actions column (RGN-01 — direct icon buttons, no three-dot menu):**

- Delete button: `Trash2` icon (Lucide, size 15), `text-subtle hover:text-red`, aria-label `"Delete {name}"`
- Both buttons sit in the same cell, gap-2 between them
- Actions cell opacity: `opacity-35 group-hover:opacity-100 transition-opacity` (matches DataTable row-actions pattern)

### Surface 4 — Create Region Modal (RGN-03 / RGN-04 / RGN-05 / RGN-06)

**Modal props:**
- `title="Create Region"`
- `subtitle="Enter a name and ID for the new region."`
- `size="default"` (max-width 520px)

**Fields:**

| Field | ID | Type | Validation | Placeholder |
|-------|----|------|------------|-------------|
| Region Name | `create-region-name` | `text` | Required, 2–60 chars | `"e.g. North West"` |
| Region ID | `create-region-id` | `text` | Required, 2–10 chars, `[A-Z0-9]` pattern | `"e.g. NW001"` |

**Auto-ID behavior (RGN-04 / RGN-05):**
- State variable: `autoMode: boolean` — starts `true`
- On every `Region Name` keystroke while `autoMode === true`: compute ID as first letter of each word (uppercased, max 4 chars) + `String(regions.length + 1).padStart(3, "0")`. Example: "North West", 3 regions → `"NW004"`
- On `Region ID` field `onChange` by user: set `autoMode = false`, stop overwriting
- On `Region ID` field `onChange` where `e.target.value === ""`: set `autoMode = true`, resume auto-population
- ID field `data-testid="field-region_id"`; add `data-auto-mode={autoMode}` for test assertions

**Field label style:** uppercase, `text-[12px] font-semibold text-subtle tracking-[0.05em] mb-1`

**Input style (normal):** `w-full px-3 py-2 text-[13.5px] bg-white border border-line rounded-md focus:outline-none focus:ring focus:ring-black/[0.06] focus:border-ink`

**Input style (error):** same + `border-red`

**Inline error style (RGN-06):** `mt-1 text-[12px] text-red`, `role="alert"`, `data-testid="error-{field-id}"`

**Footer buttons:**
- Cancel / Discard: `px-3.5 py-2 bg-white text-ink border border-line rounded-md text-[13.5px] font-normal hover:bg-line-soft`
- Submit "Create Region": `px-3.5 py-2 bg-yellow text-black border border-yellow-hover rounded-md text-[13.5px] font-semibold hover:bg-yellow-hover disabled:opacity-60`
- Submit shows spinner `w-3.5 h-3.5 border-2 border-black/20 border-t-black rounded-full animate-spin` when `submitting === true`

**Duplicate ID error (RGN-06):** Server returns 400 with `region_id` field error. Map to inline error beneath the Region ID field with exact copy: `"This Region ID is already in use."`

Source: `CreateOrgModal.tsx` — inputCls, Field, footer button patterns. `07-CONTEXT.md` §Auto-ID sequence number.

### Surface 5 — Edit Region Modal (RGN-08)

**Modal props:**
- `title="Edit Region"`
- `subtitle="Update the region name or ID."`
- `size="default"`

**Fields:** same as Create, both editable, both pre-filled with existing values

**Key differences from Create:**
- `autoMode` is permanently `false` — typing in Region Name does NOT update Region ID
- Clearing Region ID leaves it empty; user must type a valid ID (no auto-resume in edit mode per `07-CONTEXT.md` §Edit mode Region ID)
- Submit button label: `"Save Region"`

**Footer buttons:** same pattern as Create modal (Cancel + Save Region)

Source: `07-CONTEXT.md` §Edit mode Region ID, RGN-08.

### Surface 6 — Delete-Blocked Popup / RGN-10 (Amber ConfirmModal)

**ConfirmModal props:**
```
variant="amber"
title="Cannot delete region"
confirmLabel — not applicable; this is an INFO popup, not a destructive action
```

**Interaction contract:**
- This popup has NO confirm action (it is purely informational — user cannot proceed to delete)
- Footer: single "Got it" button only (no confirm button)
- `ConfirmModal` is used for layout consistency but `onConfirm` is a no-op; OR implement as a plain `Modal` with `size="sm"` if the ConfirmModal footer layout forces two buttons
- Preferred implementation: use `Modal` directly with `size="sm"` and single "Got it" footer button, with manual amber icon block matching `ConfirmModal`'s icon layout

**Content:**
- Icon: `AlertTriangle` (Lucide, 22px) in `bg-amber-tint text-amber` container (`w-11 h-11 rounded-confirm-icon`)
- Title: `"Cannot delete region"` — `text-[18px] font-semibold text-ink`
- Body: `"This region has {count} shop{count > 1 ? 's' : ''} assigned to it. Reassign or remove all shops before deleting this region."` — `text-[13.5px] text-muted leading-[1.5]`
- Link: `"Manage Shops"` — `text-yellow hover:text-yellow-hover underline font-normal`, href = `/admin/org/shops/?region={region.pk}`
- Footer button: `"Got it"` — same cancel button style as ConfirmModal

Source: `ConfirmModal.tsx`, `07-CONTEXT.md` §Delete guard, RGN-10, XMOD-02.

## Accessibility Contract

- All interactive elements keyboard-accessible (inherited from `Modal` FocusTrap + `DataTable` button elements)
- Icon-only buttons (Edit, Delete in table) have `aria-label="Edit {name}"` / `aria-label="Delete {name}"`

## Data & API Contract (Frontend Boundary)

**Endpoint:** `GET /api/v1/regions/` → `RegionRow[]`
**Endpoint:** `POST /api/v1/regions/` → `RegionRow`
**Endpoint:** `PATCH /api/v1/regions/{id}/` → `RegionRow`
**Endpoint:** `DELETE /api/v1/regions/{id}/` → 204 or 409 (shops assigned)

```typescript
interface RegionRow {
  id: number;
  name: string;
  region_id: string;   // e.g. "NW004"
  created_at: string;  // ISO 8601
}

interface CreateRegionPayload {
  name: string;
  region_id: string;
}

interface UpdateRegionPayload {
  name?: string;
  region_id?: string;
}
```

**Delete guard response (RGN-10):** Server returns HTTP 409 with body `{ "shop_count": N }` when region has shops. Widget checks for 409 and opens amber popup, not red popup.
