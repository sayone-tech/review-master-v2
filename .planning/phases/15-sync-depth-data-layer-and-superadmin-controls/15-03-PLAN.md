<objective>
Thread an optional `start_date: datetime | None` parameter through `fetch_and_persist_reviews` and `_persist_page` in `apps/reviews/services/sync.py`. When `trigger == "initial"`, compute `start_date` from the already-fetched `shop.sync_depth` value inside `fetch_and_persist_reviews` (no second DB fetch). When `start_date is not None`, `_persist_page` skips any normalised review whose `review_create_time < start_date`. Incremental and manual triggers default `start_date=None` and behave exactly as before.

Purpose: Implements BKFL-01/02/03 — the backfill date filter for configurable sync depth.
Output: Sync service filters by date when appropriate; tests cover all three depth values plus incremental regression.
</objective>
