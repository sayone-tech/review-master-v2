|----------|-------------|
| Celery worker → Redis | Token-bucket counters are shared cross-worker state; per-org key scoping prevents one org's enrichment volume bleeding into another's limit |
| Settings → broker routing | Queue names define where tasks execute; a wrong fallback could route tasks to a non-existent queue (silent drop) |
