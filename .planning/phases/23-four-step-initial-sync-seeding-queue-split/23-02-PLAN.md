<objective>
Build the finalising pass (SEED-04, Step 4): a `tag-merge`-queue task that
resolves residual duplicate canonical tags by case-insensitive string match,
re-points the loser's `ReviewTag.canonical_tag` FKs to the winner in one UPDATE,
deletes the loser, backfills null `canonical_tag` stragglers, refreshes
`OrgCanonicalTag.review_count` from an aggregate, and emits `sync.finalising.progress`
then `sync.complete`. Resolves the Phase 22 D-03 deferral (review_count is a
cache refreshed here, never incremented inline).

Purpose: This task is dispatched at the end of `run_initial_backfill` (Plan 03).
Building it first means Plan 03's dispatch has a real, tested task to call, and
the routing (tag-merge) is already in settings from Plan 01.
Output: New `finalise.py` service, extended canonical_tags selectors, new
`finalize_canonical_tags_task`, new `test_finalise.py`.
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Celery task arg → DB mutation | `organisation_id` arrives as a task argument; the finalising pass must operate only on that org's rows |
| Concurrent finalising vs Phase-25 merge | Both run on the tag-merge queue and mutate the same OrgCanonicalTag/ReviewTag rows |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-23-03 | Tampering | finalising merge cross-org | mitigate | Every OrgCanonicalTag/ReviewTag query filtered by `organisation_id=organisation_id` (CLAUDE.md §9); task receives org id explicitly, never infers it |
| T-23-04 | Elevation of Privilege | concurrent merge replay | mitigate | Per-org `lock:tag_merge:org:{org_id}` distributed lock with early return prevents two finalising/merge tasks colliding on the same org |
| T-23-05 | Denial of Service | unbounded backfill/count scan | mitigate | Straggler backfill bounded to 500/batch; review_count refresh is a single aggregate (Pitfall 3 — EXPLAIN-ANALYZE flagged for large orgs), not per-row |
| T-23-SC | Tampering | npm/pip installs | accept | No new packages this phase (RESEARCH.md audit N/A) |
</threat_model>
