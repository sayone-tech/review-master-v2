<objective>
Deliver the frontend half of SYNC-REL-01: add a snapshot-poll fallback to the ProgressModal so
a missed or dropped WebSocket event no longer freezes the modal. The modal keeps its existing
WebSocket (the primary, low-latency path) and ADDS a periodic poll of the Plan-01 GET endpoint;
the poll only ever moves state forward (merge by `last_update_at`), and stops on terminal state
and on close.

Purpose: The modal self-heals — the "reopen from the notification to refresh" workaround is no
longer needed.

Output: A `fetchSyncProgress` api helper, a poll-fallback effect in ProgressModal with a
forward-only merge guard, and tests covering interval-poll, merge-forward-only, and stop-on-terminal/close.
</objective>
