class IsOrgAdmin(BasePermission):

    def has_permission(self, request, view) -> bool:
        user = request.user
        if not user or not user.is_authenticated:
            return False

            getattr(user, "role", None) == User.Role.ORG_ADMIN

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-18-02-01 | Elevation of Privilege | POST /merge/ endpoint | mitigate | IsOrgAdmin permission class on merge_action via get_permissions() override; Staff gets 403 |
| T-18-02-02 | Tampering | merge_action_items() IDOR | mitigate | select_for_update().filter(organisation_id=organisation_id) validates all items belong to caller's org before any mutation |
| T-18-02-03 | Information Disclosure | Cross-scope merge exposing BRAND items to Staff indirectly | mitigate | D-05 scope validation in service prevents cross-scope merges; list selector canonical__isnull=True filter applies after Staff scope filter |
| T-18-02-04 | Tampering | Chained canonical chains (A→B→C circular) | mitigate | D-08 check: primary.canonical_id must be None before merge proceeds |
| T-18-02-05 | Tampering | D-17: mutating a merged duplicate via PATCH/status | mitigate | perform_update() guard + service-layer ValidationError on transition_status/assign/add_note |
| T-18-02-SC | Tampering | npm/pip installs | accept | No new packages introduced in this plan |
