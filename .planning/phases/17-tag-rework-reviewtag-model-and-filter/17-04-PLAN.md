| Browser to /api/v1/reviews/tags/ | Frontend fetches tag labels from a backend that enforces org scoping |
| User chip click to query param | Chip label passed to filter array then serialised into URL query param |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-17-10 | Tampering | Chip click to applyFilters | accept | Label comes from the backend API response (org-scoped); it is rendered as JSX text content (not innerHTML), so XSS is not applicable |
| T-17-11 | Information Disclosure | fetchTagList | accept | fetch uses credentials same-origin; backend enforces org scoping; frontend renders only what the backend returns |
| T-17-12 | Tampering | buildQs tags serialisation | accept | tags array is serialised with Array.join; labels originate from API response; no user-typed input enters the query param directly except through the dropdown selection which the backend validates via iexact lookup |
</threat_model>
