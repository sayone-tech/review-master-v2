<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser → POST /api/v1/reviews/{id}/generate-reply/ | CSRF-protected via X-CSRFToken header from cookie |
| generated draft → textarea | Server-generated plain text inserted into a controlled React state variable; never rendered as HTML |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-19-08 | Tampering | generateReply API call | mitigate | X-CSRFToken header added by the existing headers() helper for all POST requests — CSRF protection is automatic |
| T-19-09 | Information Disclosure | generated draft in textarea | accept | Draft is plain text inserted into React state (setComment(draft)) and rendered as textarea value — no HTML injection vector; no sensitive data exposed |
| T-19-10 | Spoofing | tone parameter | accept | tone value is one of ["professional", "friendly"] chosen by the user from explicit pill buttons; the serializer on the backend rejects anything else with 400 |
| T-19-11 | Denial of Service | rapid Generate button clicks | mitigate | Backend enforces 10/minute ScopedRateThrottle; frontend disables pills during loading (generatingTone !== null) preventing concurrent calls from the same component instance |
| T-19-SC | Tampering | npm/pip/cargo installs | accept | no new packages; Loader2 and Sparkles are already in lucide-react |
</threat_model>
