### Critical Integration Gap — INT-01

**`django-ses` and `boto3` absent from `pyproject.toml`**

- **Affects:** EMAL-01, EMAL-02, EMAL-03 in production
- **Impact:** `config/settings/production.py` sets `EMAIL_BACKEND = "django_ses.SESBackend"`. The package is not installed. Any production deployment will raise `ModuleNotFoundError: No module named 'django_ses'` on the first email send (org creation, resend invitation, or password reset).
- **CI gap:** `manage.py check --deploy` validates settings values, not import paths. The CI deploy-check step passes despite this gap.
- **Fix:** Add `django-ses==4.3.0` (or latest) and `boto3==1.35.0` (or latest) to `[project.dependencies]` in `pyproject.toml` and run `uv lock`.

### Non-Critical Integration Gap — INT-02

**`/admin/organisations/` HTML view missing role-based access**

- **Affects:** No milestone requirement
- **Impact:** `apps/organisations/views.py:organisation_list` has only `@login_required`. An `ORG_ADMIN` logging in is redirected to `/admin/organisations/` (via `LOGIN_REDIRECT_URL`), which renders the page HTML, but the React widget's API call to `/api/v1/organisations/` returns 403. The table stays in a stuck-loading state. No requirement is violated; this is a latent UX confusion gap.
