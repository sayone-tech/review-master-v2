## Phase 18 — Action Item Duplicate Merge (D-01 .. D-20)

All 20 requirements satisfied. Full text in `.planning/phases/18-action-item-duplicate-merge/18-CONTEXT.md`.

Key acceptance criteria:

- [x] Org Admin selects 2+ AI-extracted action items and merges via two-step modal
- [x] Merged duplicates hidden from default list; canonical shows "+N" badge
- [x] Canonical detail shows "Also reported in" with shop / source review date / star rating
- [x] "Mark as duplicate of…" picker on single-item detail
- [x] Merged duplicates are read-only (400 on status/assignment/notes mutation)
- [x] `POST /api/v1/action-items/merge/` restricted to Org Admin (Staff 403)
- [x] Service validates same org, same scope (SHOP/BRAND), source=AI, non-chained primary

## Phase 19 — AI Reply Generation (D-01 .. D-25)
