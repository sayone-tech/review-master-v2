# Milestone Archive: v0.5 — Configurable Sync Depth

**Shipped:** 2026-05-16
**Phases:** 15–16 (2 phases, 6 plans)
**Requirements:** 9/9 (see [`v0.5-REQUIREMENTS.md`](v0.5-REQUIREMENTS.md))
**Git tag:** `v0.5`

## Goal

Let Superadmins enable a per-org "configurable sync depth" flag; when
enabled, Org Admins choose how far back the initial review backfill goes
(1 year / 2 years / all time) at shop creation time — replacing the
hard-coded 2-year default.

## Phases

### Phase 15: Sync Depth Data Layer and Superadmin Controls — completed 2026-05-15

**Goal:** Data model, migration, and service layer for configurable sync
depth are in place — Organisation carries `allow_custom_sync_depth`
(Superadmin-controlled at create + edit), Shop carries `sync_depth`
(visible on shop detail), and the initial backfill Celery task reads
that field to compute the Google API `start_date`.

**Requirements satisfied:** SYNC-01, SYNC-02, SYNC-03, SDEP-02, SDEP-03,
BKFL-01, BKFL-02, BKFL-03

**Plans (4):**

- [x] 15-01 — Organisation `allow_custom_sync_depth`: model, migration, service, serializers, tests
- [x] 15-02 — Shop `sync_depth` TextChoices field default TWO_YEARS: model, migration, serializer, tests
- [x] 15-03 — Backfill date filter: thread `start_date` through `fetch_and_persist_reviews` and `_persist_page`
- [x] 15-04 — Frontend: Superadmin toggle in Create/Edit/View Org modals + 'Review history' row in ShopDetailsModal

### Phase 16: Org Admin Shop Creation — Conditional Depth Selector — completed 2026-05-16

**Goal:** Org Admins whose organisation has "Allow configurable sync depth"
enabled see a "Review History" dropdown in the shop creation form;
selecting a depth persists it to the shop and drives the backfill;
Org Admins without the flag enabled never see the dropdown and always
get the 2-year default.

**Requirements satisfied:** SDEP-01

**Plans (2):**

- [x] 16-01 — Backend: ShopCreateSerializer sync_depth field, create_shop() kwarg, shop_list view context, template bootstrap tag
- [x] 16-02 — Frontend: types.ts, entrypoint, ShopModals, CreateShopModal conditional Review History dropdown

## Key Accomplishments

- Organisation gained `allow_custom_sync_depth` BooleanField — Superadmin
  toggle on org create / edit / detail
- Shop gained `sync_depth` TextChoices field (`ONE_YEAR`, `TWO_YEARS`,
  `ALL_TIME`) defaulting to `TWO_YEARS`
- Initial backfill Celery task now computes `start_date` from per-shop
  sync_depth — no date filter when "All time"
- Conditional UI: shop creation form shows the Review History dropdown
  only when the parent org has the flag enabled
