1. `credit_cost(text)`: the single authoritative price for a review (CRED-04, D-08..D-10).
2. The virtual-balance selectors. `get_shop_credit_balance` returns a frozen `CreditBalanceView`, and `annotate_credit_state` gives one-query list annotation. Both report the organisation's live allocation for shops with no current-month row and never write a row (CRED-05, D-11..D-13).

Output: `services/credit_cost.py`, `selectors/balances.py`, test_credit_cost / test_settings / test_selectors, the CLAUDE.md §3 update, and recorded auditor findings.
