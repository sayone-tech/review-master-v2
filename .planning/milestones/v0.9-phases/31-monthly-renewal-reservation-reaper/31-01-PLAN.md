| Boundary | Description |
|----------|-------------|
| Celery Beat -> worker -> credits DB | System job with no user input; writes ledger and audit rows for every tenant |
| Concurrent sweeps (Beat + manual shell run) -> one balance row | Overlapping writers on the same balance |
| Late commit (request thread) -> lapsed balance | Phase 30's settle path reads lapse state outside the lapse lock |
