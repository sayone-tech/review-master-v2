## Phase 20 — AI Guardrails (D-01 .. D-33)

All 33 requirements satisfied. Source: `.planning/phases/20-ai-guardrails/20-CONTEXT.md`.

Key acceptance criteria:

- [x] Review text >4000 chars (env-configurable) truncated with `"…[truncated]"` before any OpenAI call
- [x] Review text flagged by high-severity moderation categories (sexual_minors, hate_threatening, violence_graphic, self_harm_intent, self_harm_instructions — underscore form) blocks the OpenAI enrichment call and sets `Review.enrichment_status=FAILED` with `enrichment_error_code="content_moderated"`
- [x] AI reply generation: input moderation blocks before OpenAI; output moderation blocks before the draft reaches the user; replies >300 words truncated at sentence boundary with `" (Please review and complete before sending.)"` suffix
- [x] `ContentModeratedException` maps to HTTP 422 with canonical body `{code: "content_moderated", detail: "AI reply isn't available for this review. Please write your reply manually."}`
- [x] Moderation API outage: fail-open with one retry after 1s; ERROR log on second failure
- [x] `AiUsageLog` rows for moderated events: input-moderated → status=MODERATED + zero tokens; output-moderated → status=MODERATED + real tokens + error_code="output_moderated"
- [x] `retry_failed_enrichments_task` excludes rows with `enrichment_error_code="content_moderated"`
- [x] All `AiUsageLog` writes for moderation events happen OUTSIDE any `transaction.atomic()` block

## Phase 21 — Audit Log Viewer (REQ-01 .. REQ-09)

All 9 requirements satisfied. Source: `.planning/phases/21-audit-log-viewer/21-CONTEXT.md`.

Key acceptance criteria:

- [x] `GET /api/v1/audit-logs/` returns cursor-paginated results scoped to caller's org; Staff receives only entries from their accessible shops + SHOP-scope action items
- [x] Response has `next`/`previous` cursor URLs, no `before_data` field; includes `actor_name` (null for system actions)
- [x] Filters work: `entity_type` (review/action_item), `actor` (user ID or "system"), `date_from`/`date_to` (ISO date), `shop`
- [x] Superadmin receives 403; unauthenticated receives 401; throttle 120/minute
- [x] "Activity Log" nav item appears in `sidebar_org.html` for both `ORG_ADMIN` and `STAFF_ADMIN`
- [x] `/admin/org/activity-log/` renders Django template with React widget at `#audit-log-root`
- [x] React widget shows 5-column table with expandable JSON detail panel, Type pills (Reply / Action Item), cursor pagination, filter bar with 30d default date preset
