# Requirements Archive: v0.5 — Configurable Sync Depth

**Milestone shipped:** 2026-05-16
**Phases:** 15–16
**Coverage:** 9/9 requirements satisfied

## Superadmin Org Settings (SYNC)

- [x] **SYNC-01**: Superadmin can enable "Allow configurable sync depth" when creating an organisation
- [x] **SYNC-02**: Superadmin can enable/disable "Allow configurable sync depth" when editing an existing organisation
- [x] **SYNC-03**: The "Allow configurable sync depth" state is visible on the org detail page

## Shop Sync Depth (SDEP) — set at shop creation only

- [x] **SDEP-01**: When the parent org has "Allow configurable sync depth" enabled, the Org Admin sees a "Review History" dropdown in the shop creation form with options: "Last 1 year", "Last 2 years", "All time"
- [x] **SDEP-02**: When the parent org does not have "Allow configurable sync depth" enabled, no dropdown is shown and the shop is always created with "Last 2 years" (the system default)
- [x] **SDEP-03**: The selected review history depth is shown on the shop detail page

## Initial Backfill Behaviour (BKFL)

- [x] **BKFL-01**: Initial backfill for a shop configured to "Last 1 year" fetches only reviews created within the last 12 months; reviews older than 12 months are not synced
- [x] **BKFL-02**: Initial backfill for a shop configured to "Last 2 years" (the default) fetches only reviews created within the last 24 months
- [x] **BKFL-03**: Initial backfill for a shop configured to "All time" fetches all available reviews — no date filter is applied to the Google API request
